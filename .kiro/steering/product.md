# Product Overview

This is a Deep Learning educational project focused on teaching neural networks and convolutional neural networks using TensorFlow and Keras. The course covers fundamental concepts from basic neural networks to advanced convolutional architectures, with practical implementations in Jupyter notebooks.

## Main Topics

- Introduction to Deep Learning and TensorFlow
- Neural Networks fundamentals and training (forward/backward propagation, gradient descent)
- Cross-Entropy and loss functions
- Advanced neural network architectures
- Convolutional Neural Networks (CNNs)
- Advanced CNN architectures

## Practice Project

The practical component involves working with the HAM10000 skin cancer dataset for medical image classification, demonstrating real-world application of deep learning techniques.
