# Project Structure

## Root Directory

```
/
├── notebooks clase/          # Educational notebooks (course materials)
├── practica/                 # Practice exercises and project materials
├── .venv/                    # Python virtual environment
└── Introducción - DeepLearning.pptx  # Course presentation
```

## Notebooks Directory (`notebooks clase/`)

Contains sequential learning modules covering the deep learning curriculum:

1. **1_Introducción_al_Deep_Learning_y_Tensorflow (1).ipynb**
   - Introduction to Deep Learning concepts
   - TensorFlow basics and tensor operations
   - Google Colab setup

2. **2_Redes_neuronales.ipynb**
   - Neural network fundamentals
   - Forward and backward propagation
   - Gradient descent implementation

3. **3_Cross_Entropy.ipynb**
   - Loss functions
   - Cross-entropy for classification

4. **3_Redes_neuronales_avanzadas.ipynb**
   - Advanced neural network architectures
   - Activation functions
   - Weight initialization

5. **4_Redes_convolucionales.ipynb**
   - Convolutional Neural Networks (CNNs)
   - Convolution operations
   - Image classification

6. **5_Redes_convolucionales_avanzadas.ipynb**
   - Advanced CNN architectures
   - Transfer learning concepts

## Practice Directory (`practica/`)

Contains materials for the practical project:

- **about_dataset.md** - Information about the HAM10000 dataset and download links
- **enunciado.pdf** - Project assignment (binary file)
- **guion.pdf** - Project guidelines (binary file)

## Naming Conventions

- Notebooks use Spanish naming with underscores
- Sequential numbering for course progression
- Descriptive names indicating content

## Code Organization

- Each notebook is self-contained with theory and practical examples
- Code cells include Spanish comments
- Mathematical formulas use LaTeX notation
- Visualizations use matplotlib for inline display
