# Technology Stack

## Primary Language
- **Python 3** (Python 3.7.4+)

## Core Libraries and Frameworks

### Deep Learning
- **TensorFlow** - Primary deep learning framework
- **Keras** - High-level neural networks API (integrated with TensorFlow)

### Scientific Computing
- **NumPy** - Numerical operations and array manipulation
- **SciPy** - Scientific computing (signal processing, image operations)

### Computer Vision
- **OpenCV (cv2)** - Image processing and manipulation

### Visualization
- **Matplotlib** - Plotting and visualization

## Development Environment

- **Google Colab** - Primary development platform with GPU support (NVIDIA K80)
- **Jupyter Notebooks** - Interactive development and documentation

## Data Sources

- HAM10000 dataset (skin cancer images)
  - Available via Google Drive, Harvard Dataverse, or Kaggle
  - Used for practical classification exercises
